# Clapper

**_Clapper_** - простой сервис для быстрого поиска фильмов с фильтрами. Ищите по своим предпочтениям и добавляйте понравившееся в избранное!

## Установка

После успешно клонирования репозитория необходимо установить все требуемые для работы пакеты

```bash
npm install
```

В это время следует получить API-ключ у бота (https://t.me/kinopoiskdev_bot). Скопируйте `.env.default` файл и переименуйте его в `.env`, после чего вставьте ключ напротив поля **VITE_API_KEY**. Должно получиться что-то наподобие такого

```
VITE_API_KEY=1234567-1234567-1234567-1234567
```

Теперь можно собрать проект

```bash
npm run build
```

И наконец запустить сервер

```bash
npm run preview
```

В выводе будет что-то типо

```bash
> mobx-app@0.0.0 preview
> vite preview

  ➜  Local:   http://localhost:4173/
  ➜  Network: use --host to expose
  ➜  press h + enter to show help
```

Осталось только открыть ссылку в браузере (в моем случае http://localhost:4173/) и наслаждаться проделанной работой
